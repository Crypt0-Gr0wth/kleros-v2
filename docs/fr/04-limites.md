# 4. Limites et intégration

Les intégrateurs doivent gérer les délais, les frais, les paramètres de cour et les résultats contestés. Ce parcours décrit le code sans installation, compilation, test ni déploiement.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
